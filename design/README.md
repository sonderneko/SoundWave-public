# Space-compressed 音乐播放器设计稿（静态参考）

`space-compressed.html` 是用户提供的多页面音乐播放器视觉参考，仅用于离线评审与设计映射。它不属于 Android 运行时资源、不参与 Gradle 打包，也不作为业务逻辑或交互实现的依赖。仓库内副本应保持为无脚本的静态 HTML/CSS/内嵌图片文档；不要为它启动本地服务或执行原型代码。

## 视觉基准

- 浅色：暖纸白背景、白色表面、炭黑文字、珊瑚强调色；蓝色用于搜索强调，黄绿色用于播放进度。
- 深色：绿黑背景与深色表面，使用高对比浅色文字；交互语义与浅色模式一致。
- 页面：首页、搜索、音乐库、歌单广场、排行榜、专辑/歌单详情、沉浸播放、队列、听歌档案、播放历史、音源/设置及加载、空、错误、已完成状态。
- Android 页面保留真实数据、导航、播放与操作回调，只调整布局和视觉呈现；设置页继续以用户指定的 1.0.644 APK 布局与按钮样式为准。

Android 实现使用 Jetpack Compose 原生组件，不读取此文档中的 HTML、CSS 或原型脚本作为运行时资产。
