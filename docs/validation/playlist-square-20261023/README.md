## 真正修复的酷我专区缺口

[酷我经典老歌专区原始响应](live/kw-zone-211.json)根部是数组，每组通过 `list` 提供条目。旧 `parseNativePlaylistSquare` 一开始即执行 `JSONObject(raw)`，即使返回对象也只递归 child/data，不认识 list，导致此接口真实歌单无法进入结果。

修复 `PlaylistSquarePaging.kt`：对酷我 digest=43 先解析数组，兼容旧 data/child 对象包装，遍历 list/child/data，只收 digest=8 的真实歌单，按ID去重；专辑、歌曲、导航节点不冒充歌单。该响应含17个不同的真实歌单，全部保留。没有新增未知分页参数，也不声称这17个就是酷我完整“经典”分类；专区和普通标签目录是不同来源。

## 其他平台的检查结论

- 网易：固定 limit=30，offset=(page−1)×30，优先使用 `more`。独立只读核验 offset 0/30 可返回不同页；未证实漏页。

网易/咪咕的独立只读核验仅作为补充观察，未将未归档响应计入固定条目数回归。
