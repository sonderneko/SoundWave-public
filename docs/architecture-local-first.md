# SoundWave 数据与账号边界（当前实现说明）

> 本文更新于 2026-10-07，用于替换旧版蓝图中已经过期的“五平台账号登录、Cookie 增强与账号推荐”描述。它说明的是客户端代码边界，不代表本次修改了 VPS/服务端。

## 当前功能边界

### 五个平台公开数据

网易云、QQ 音乐、酷狗、酷我、咪咕仍可按现有代码路径获取公开搜索结果、榜单、歌单/专辑详情、封面、歌词和播放地址。各功能依实际平台适配器使用客户端匿名直连、既有服务端回退或用户配置的 LX 脚本，不在本文声称这些接口全部由客户端直连。

五个平台的匿名搜索、榜单与普通歌单推荐继续保留；首页本地听歌画像推荐继续由 `PersonalRecommendations` 生成。网易云私人雷达和账号态每日推荐因依赖第三方账号登录而已从客户端 UI、网络调用、状态及诊断数据路径移除。

### 第三方音乐平台账号（已移除）

客户端不再提供五平台的网页登录/WebView、扫码/手机号或 Cookie 粘贴入口；不再持久化五平台会话、自动为播放器/下载/脚本请求注入账号 Cookie，不再探测第三方账号或导入其账号歌单，也不再使用账号态播放增强取链器。

升级时由 `LegacyPlatformAuthCleanup` 一次性清理旧第三方账号 SharedPreferences、专用 Android Keystore alias，以及已知五个平台登录域名的 WebView Cookie。清理范围不包含 SoundWave 自有账号凭据、头像、收藏、歌单、播放历史或下载文件。网易云榜单/公开歌单直连在接口需要时仅使用固定的 `os=pc` 匿名协议标记，该标记不含用户身份或账号凭证。

### SoundWave 自有账号与本地数据（保留）

SoundWave 自有账号登录及其云端歌单/收藏/播放历史/头像同步仍由现有账户与 `ApiClient` 路径处理。用户在本地创建的歌单、收藏、本地音乐、播放历史、已下载歌曲和普通在线/离线播放功能均保留；移除第三方账号导入入口不会删除已有的本地用户数据。

`PlaylistImportChecker` 仍服务现有歌单导入/播放链路，不负责第三方账号认证，也不在本次移除范围内。

### 用户脚本与服务端

`ScriptRuntime` 的用户脚本配置、脚本优先级及脚本自带请求头仍保留；应用不再自动向脚本请求附加五平台账号凭证。此次未修改 Cloudflare/VPS 或服务端实现，因此旧后端端点是否仍部署、是否还有其他客户端调用，需另行审查服务端代码与运行配置才能确认。

## 主要实现位置

- `ApiClient.kt`：SoundWave 自有账户 API、常规匿名/服务端数据请求与公共取链。
- `source/direct/`：各平台公开匿名接口适配、歌词、榜单、歌单与普通直连播放解析。
- `UrlResolver.kt`、`PlayerService.kt`、`DownloadHelper.kt`：普通取链回退、在线播放/本地播放与下载；不再使用内置五平台账号 Cookie。
- `HomePage.kt`、`PersonalRecommendations.kt`：公开首页数据与基于本地听歌/收藏的推荐。首页顶部栏的无状态布局位于 `ui/home/HomeTopBar.kt`；pager 同步以及 feed、推荐、网络、缓存和分页状态仍由 `HomePage` 持有。
- `LegacyPlatformAuthCleanup.kt`：旧版第三方音乐账号凭证的一次性清理。
