# 新增用户验收要求

## 账号同步/WebDAV
- 输入时弹层不能被键盘顶出屏幕；按实际可用高度滚动，避免嵌套IME padding重复消费。
- 成功验证后安全保存凭据，下次直接复用；加密保存失败必须说明，不能假装记住。
- WebDAV明确区分首次配置、已保存账号、同步状态、编辑/忘记；密码默认遮罩；账号owner和授权门闸不放宽。
- 录屏2.923秒，后半抽帧大面积黑屏，不能声称影像证实具体IME原因；以用户报告与代码路径定位。

## 备份迁移
- 普通导入备份会恢复当前数据；隔离导入和旧版本机复制创建不覆盖/不自动启用副本，语义不同不得静默合并。
- 兼容功能收纳低频旧版资料迁移，清楚解释差异，保留预览/独立确认/回滚能力。
- 不因收纳入口删除任何现有用户数据。

## 播放历史
- 只移除歌曲长按功能（菜单/震动/多选触发）；保留点击播放、左滑删除及来源/时间。
- 不影响其他页面歌曲长按。
